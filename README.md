# projectkoios-obsidian

Obsidian vault management and knowledge curation for Project Koios.

The package provides reusable vault configuration and layout contracts without
hardcoding a user's vault path or directory conventions.

- [Vault layout architecture](docs/architecture.vault-layout.md)
- [Vault layout user guide](docs/user-guide.vault-layout.md)

Repository routing is documented in `projectkoios-bootstrap/maps/repositories.md`.
